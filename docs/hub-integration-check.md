# Verificação da integração com o Hub

Procedimento do ambiente de testes:

1. Atribua uma issue a um membro e adicione-a ao board.
2. Marque o item como Done: uma tarefa técnica sem PR mergeado não gera entrega.
3. Abra e faça merge de um PR com `Closes #N` na descrição.
4. Confira a entrega pendente no Hub, com o link do PR e os créditos.
5. Reprocesse o evento: a mesma entrega não deve ser duplicada.
